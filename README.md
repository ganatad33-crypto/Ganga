# בוט סיכום קבוצות וואטסאפ

כלי שמתחבר לחשבון הוואטסאפ שלך, מאזין לקבוצות שבחרת, ומייצר סיכום תמציתי של השיחה (נושאים, החלטות, משימות) באמצעות Claude — לפי תזמון קבוע או על פי דרישה.

## ⚠️ לפני שמתחילים

הכלי מתחבר דרך "מכשיר מקושר" (כמו וואטסאפ ווב), ולא דרך ה-API הרשמי של מטא — כי אין API רשמי שמאפשר קריאה פסיבית של קבוצות שאתה חבר בהן. זו שיטה נפוצה לבוטים אישיים, אבל **אינה בשימוש הרשמי המאושר על ידי מטא/וואטסאפ**, וקיים סיכון (נמוך אך לא אפסי) לחסימה זמנית של המספר. מומלץ להשתמש בזה על החשבון האישי שלך ובאחריותך, ולא על מספר קריטי לעסק.

הכלי שומר רק טקסט של הודעות מהקבוצות שהגדרת (לא מדיה), לצורך יצירת הסיכומים.

## התקנה

```bash
npm install
cp .env.example .env
```

ערוך את `.env` והכנס בו את `ANTHROPIC_API_KEY` שלך.

## הגדרת הקבוצות למעקב

```bash
cp config/groups.example.json config/groups.json
```

ערוך את `config/groups.json` ורשום את שמות הקבוצות שברצונך לעקוב אחריהן:

```json
{
  "groups": [
    { "name": "המשפחה שלי" },
    { "name": "עבודה - צוות פיתוח" }
  ]
}
```

ההתאמה נעשית לפי הכלה (case-insensitive) של השם בתוך שם הקבוצה בפועל. אם יש כמה קבוצות בעלות שמות דומים, הרץ:

```bash
npm run list-groups
```

זה יתחבר לוואטסאפ (בפעם הראשונה תתבקש לסרוק QR) ויציג את כל הקבוצות עם ה-JID המדויק שלהן. אפשר להשתמש ב-JID במקום/בנוסף לשם כדי להיות מדויקים לגמרי:

```json
{ "jid": "123456789012345678@g.us", "name": "שם לתצוגה" }
```

## הפעלה

```bash
npm start
```

בפעם הראשונה יוצג קוד QR בטרמינל — סרוק אותו מהטלפון (וואטסאפ → הגדרות → מכשירים מקושרים → קישור מכשיר). החיבור נשמר בתיקיית `auth/`, כך שבפעמים הבאות ההתחברות אוטומטית.

הכלי ירוץ ברקע, יאזין להודעות בקבוצות שהוגדרו וישמור אותן, ויריץ סיכום אוטומטי לפי התזמון שהוגדר ב-`SUMMARY_CRON` (ברירת מחדל: כל יום ב-20:00). אם `SEND_SUMMARY_TO_SELF=true`, הסיכום גם יישלח כהודעת וואטסאפ ל"הודעה לעצמך".

הסיכומים נשמרים תמיד גם כקבצי Markdown בתיקיית `summaries/`.

### הרצת סיכום ידנית

אם רק רוצים לייצר סיכום על סמך מה שכבר נאסף (בלי לפתוח חיבור וואטסאפ חדש):

```bash
npm run summarize
```

## איפוס החיבור

אם צריך להתחבר עם חשבון אחר או ה-QR פג תוקף:

```bash
rm -rf auth/
npm start
```

## מבנה הפרויקט

```
src/
  index.js        - נקודת הכניסה: מאזין להודעות + מתזמן סיכומים
  whatsapp.js      - חיבור ל-Baileys (WhatsApp Web multi-device)
  groups.js        - התאמת קבוצות לפי שם/JID
  store.js         - שמירת הודעות לקבצי JSONL מקומיים
  summarizer.js     - קריאה ל-Claude ליצירת הסיכום
  listGroups.js     - סקריפט עזר לרשימת קבוצות + JID
  cliSummarize.js    - הרצת סיכום ידנית חד-פעמית
config/groups.json  - רשימת הקבוצות למעקב (לא נשמר בגיט)
data/               - הודעות שנאספו (לא נשמר בגיט)
summaries/          - קבצי הסיכום שנוצרו (לא נשמר בגיט)
auth/               - קרדנציאלים של החיבור לוואטסאפ (לא נשמר בגיט, סודי!)
```

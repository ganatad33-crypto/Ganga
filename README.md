# Ganga — פרויקטים

## 📁 מה יש כאן

### `portfolio/` — אתר פורטפוליו לצלם ✅
אתר תדמית מלא בעברית (RTL) לדף הצילומים: גלריה עם סינון לפי קטגוריות, לייטבוקס,
אודות, שירותים ויצירת קשר (וואטסאפ/טלפון/פייסבוק).
- לצפייה: פתחו את `portfolio/index.html` בדפדפן
- להתאמה אישית: עורכים רק את `portfolio/js/config.js` — ראו `portfolio/הוראות-התאמה-אישית.md`

### `facebook-upgrade/` — ערכת שדרוג לדף הפייסבוק ✅
מדריך מעשי מלא: קאבר ופרופיל, תבניות "אודות", 10 תבניות פוסטים, האשטגים,
לוח תוכן שבועי וצ'קליסט שדרוג.

### `guides/` — מדריכים ✅
מדריך צעד־צעד להורדת כל התמונות מפייסבוק (הכלי הרשמי + העברה ל-Google Photos).

### `panim-umazal/` — טיוטה (בהמתנה) ⏸️
שלד ראשוני של אפליקציית "פנים ומזל" (ניתוח אופי לפי תורת הפנים, אסטרולוגיה
ונומרולוגיה). הפיתוח הושהה לבקשת בעל הפרויקט — נשמר כאן להמשך עבודה עתידי.





# 📦 ניהול מלאי — מעטפות ודפי נושא

אפליקציה לניהול מלאי המחסן: מעטפות חלון (מטניר) ודפי נושא (שביט/מזל).
עובדת בטלפון, גם בלי אינטרנט, ונשמרת על מסך הבית כמו אפליקציה רגילה.

## מה יש באפליקציה

- **שתי רמות מלאי לכל פריט:** תא העמסה + מדף שוטף (שניהם בארגזים)
- **4 פעולות:** משיכה לשוטף · ספירת מדף · קליטת הזמנה · תיקון ספירה
- כפתור **"ספירת מדף מהירה"** ישירות על כל כרטיס — הפעולה הכי שכיחה ביום
- **קליטת תעודת משלוח** — חיפוש והוספה של כמה פריטים בבת אחת (כפתור 📥)
- **יומן תנועות** מלא, מקובץ לפי ימים (לשונית 📋 למטה)
- **תחזית "יספיק ל־X ימים"** — לפי השימוש בפועל של המכונות (אם יש שתי ספירות מדף) או לפי קצב המשיכות. אדום = פחות משבוע, צהוב = פחות משבועיים
- **סטטוסים:** 🔴 אזל · 🟠 חוסר · 🟡 גבולי · 🟢 תקין — החוסרים תמיד למעלה
- חיפוש + סינון (הכול / מעטפות / דפים / רק חוסרים)
- **מצב טסט** נפרד לגמרי לניסויים + איפוס לספירה המקורית
- **ייצוא דוח XLSX** (גיליון מלאי + גיליון יומן)
- **גיבוי ושחזור** של כל הנתונים בקובץ JSON
- מסך **עזרה** מלא בעברית
- כפתור **Back** של אנדרואיד סוגר חלונות כרגיל

## איך מתקינים בטלפון (אנדרואיד + כרום)

האפליקציה צריכה לשבת בכתובת אינטרנט (בחינם, חד־פעמי). אחרי זה היא
מותקנת ועובדת גם בלי אינטרנט:

1. פותחים את הכתובת של האפליקציה בכרום בטלפון.
2. מחכים שנייה — יופיע כפתור כתום **"התקנת האפליקציה למסך הבית"**. לוחצים ומאשרים.
3. אם הכפתור לא הופיע: תפריט כרום (שלוש נקודות למעלה) ← **"הוספה למסך הבית"**.
4. זהו. האייקון על מסך הבית, והאפליקציה עובדת גם בלי קליטה.

> עדיין אין כתובת אינטרנט? אפשר לבקש מקלוד להקים אחת בחינם
> (GitHub Pages) — צעד אחד ומקבלים קישור קבוע.

## איפה הנתונים נשמרים?

בטלפון עצמו (IndexedDB + גיבוי מקומי כפול). שום דבר לא נשלח לשרת.
לכן חשוב פעם בשבוע: **תפריט ☰ ← "גיבוי כל הנתונים"** — נשמר קובץ
שאפשר לשחזר ממנו הכול, גם בטלפון חדש.

## מבנה הקבצים (למי שמתחזק)

| קובץ | תפקיד |
|---|---|
| `index.html` | מסך האפליקציה |
| `js/app.js` | כל הלוגיקה |
| `js/catalog.js` | **קטלוג הפריטים** — כאן מחליפים/מוסיפים פריטים |
| `js/db.js` | שמירת נתונים (IndexedDB) + מיגרציה מהגרסה הישנה |
| `sw.js` | עבודה אופליין (בעדכון גרסה — להעלות את `VERSION`) |
| `css/app.css` | עיצוב |
| `vendor/`, `fonts/`, `icons/` | ספריות, פונטים ואייקונים — הכול מקומי, בלי תלות באינטרנט |

.

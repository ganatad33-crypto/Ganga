עברית, אנגלית, ערבית, רוסית, צרפתית, ספרדית, גרמנית, איטלקית, פורטוגזית, יפנית, סינית, קוריאנית, הינדי, טורקית, פולנית, הולנדית, יוונית, שוודית, נורווגית, דנית, פינית, מלאית וסווהילי.

מבוסס על המודל הפתוח [Chatterbox Multilingual](https://github.com/resemble-ai/chatterbox) של Resemble AI (רישיון MIT).

אחרי שינוי ב־`app.py` מריצים `python build_colab.py` כדי לעדכן את המחברת.

## הרצה על מחשב — דרישות

- Python 3.10–3.12 (מומלץ 3.11)
- כ־6GB פנויים בדיסק (ספריות + המודל, שיורד אוטומטית בהפעלה הראשונה)
- **מומלץ כרטיס מסך NVIDIA** — עם כרטיס מסך משפט נוצר תוך שניות; על מעבד בלבד זה עובד אבל לאט (יכול לקחת דקה ויותר למשפט). ב־Mac עם שבב M נעשה שימוש אוטומטי ב־MPS.

## הפעלה

**Windows:** לחיצה כפולה על `run.bat`
**Linux / Mac:** `./run.sh`

בפעם הראשונה ההתקנה לוקחת כמה דקות. אחר כך פותחים בדפדפן: http://127.0.0.1:7860

לפתיחה מהטלפון או ממחשב אחר באותה רשת: `./run.sh --host 0.0.0.0` ואז `http://<כתובת-המחשב>:7860`.

> לכרטיס NVIDIA ב־Windows ייתכן שצריך להתקין את PyTorch עם CUDA ידנית לפני ההפעלה:
> `.venv\Scripts\pip install torch==2.6.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu124`

## איך משתמשים

1. מעלים קובץ קול (WAV/MP3) או מקליטים ישר מהמיקרופון. הכי טוב: 10–30 שניות, דובר אחד, בלי מוזיקה ורעשי רקע.
2. בוחרים את שפת הטקסט.
3. כותבים טקסט. טקסט ארוך מפוצל אוטומטית למשפטים ומחובר לקובץ אחד.
4. מסמנים את אישור ההסכמה ולוחצים **צור אודיו**. אפשר להשמיע ולהוריד את התוצאה.

**טיפים:**
- אם הדגימה בשפה אחת והטקסט בשפה אחרת (למשל דגימה באנגלית וטקסט בעברית), כדאי להוריד את "קצב והיצמדות לדגימה" ל־0, אחרת המבטא של שפת הדגימה עלול לעבור לתוצאה.
- לדיבור דרמטי יותר: מעלים את "הבעה" ל־0.7 ומעלה ומורידים את "קצב" לכ־0.3.

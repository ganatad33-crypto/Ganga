# 🛠️ איך מתאימים את אתר הפורטפוליו אליך

האתר עובד כבר עכשיו — פשוט פותחים את `index.html` בדפדפן.
כל ההתאמה האישית נעשית **בקובץ אחד בלבד**: `js/config.js`.

## 1. פרטים אישיים
פתח את `js/config.js` ומלא:
- `name` — השם שלך / שם הסטודיו
- `tagline` — משפט תיאור קצר
- `about` — כמה משפטים עליך
- `phone`, `whatsapp`, `email` — פרטי הקשר (וואטסאפ בפורמט `9725XXXXXXXX`)
- `facebook`, `instagram` — קישורים לעמודים שלך

## 2. הוספת התמונות שלך
1. צור תיקייה `images` בתוך תיקיית `portfolio` (אם אינה קיימת)
2. העתק אליה את התמונות (מומלץ ברוחב 1600–2000 פיקסלים, עד ~500KB לתמונה)
3. עדכן את רשימת `photos` ב-`config.js`:
```js
{ src: "images/sunset.jpg", title: "שקיעה בחוף", category: "טבע ונוף" },
```
כל עוד קובץ חסר — האתר מציג ממלא־מקום מעוצב, כך ששום דבר לא "נשבר".

## 3. קטגוריות
שנה את רשימת `categories` לפי הז'אנרים שלך. הקטגוריה הראשונה ("הכול") מציגה את כל התמונות.

## 4. העלאה לאינטרנט (בחינם)
האפשרות הפשוטה ביותר — **GitHub Pages**:
1. בהגדרות הריפו ב-GitHub: Settings ← Pages
2. Source: Deploy from a branch ← בחר את ה-branch ואת התיקייה
3. תוך דקות תקבל כתובת אינטרנט חינמית לאתר

אפשרויות נוספות: Netlify / Vercel — גוררים את תיקיית `portfolio` לאתר שלהם ומקבלים קישור.

## 5. קישור מהפייסבוק
אחרי שהאתר באוויר — הוסף את הקישור שלו לאזור ה"אודות" בדף הפייסבוק ולפוסט הנעוץ. זה השדרוג המשמעותי ביותר לדף.

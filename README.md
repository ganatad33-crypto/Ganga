# Ganga — פרויקטים

## 📁 מה יש כאן

### `portfolio/` — אתר פורטפוליו לצלם ✅
אתר תדמית מלא בעברית (RTL) לדף הצילומים: גלריה עם סינון לפי קטגוריות, לייטבוקס,
אודות, שירותים ויצירת קשר (וואטסאפ/טלפון/פייסבוק).
- לצפייה: פתחו את `portfolio/index.html` בדפדפן
- להתאמה אישית: עורכים רק את `portfolio/js/config.js` — ראו `portfolio/הוראות-התאמה-אישית.md`

### `facebook-upgrade/` — ערכת שדרוג לדף הפייסבוק ✅
מדריך מעשי מלא: קאבר ופרופיל, תבניות "אודות", 10 תבניות פוסטים, האשטגים,
לוח תוכן שבועי וצ'קליסט שדרוג.

### `guides/` — מדריכים ✅
מדריך צעד־צעד להורדת כל התמונות מפייסבוק (הכלי הרשמי + העברה ל-Google Photos).

### `panim-umazal/` — אפליקציית "פנים ומזל" ✅
אפליקציית ניתוח אופי משולב בעברית: תורת הפנים (חכמת הפרצוף) + אסטרולוגיה + נומרולוגיה.
- **ניתוח פנים:** העלאת תמונת פורטרט וזיהוי תווי פנים אוטומטי בדפדפן (MediaPipe),
  עם אפשרות הזנה ידנית כגיבוי. התמונות לא נשלחות לשום שרת.
- **אסטרולוגיה:** חישוב אסטרונומי אמיתי של מזל השמש, מזל הירח והאופק העולה
  מתאריך, שעה ומקום לידה.
- **נומרולוגיה:** מספר מסלול חיים, מספר השם בגימטריה עברית, ושנה אישית.
- **התאמה זוגית:** ציון התאמה בין שני אנשים בחמישה תחומי חיים —
  רומנטיקה, תקשורת, קריירה, חברות ויציבות.
- לצפייה: פתחו את `panim-umazal/index.html` בדפדפן.
- ⚠️ מבוסס על מסורות עתיקות — להעשרה והשראה בלבד, לא כלי אבחון.

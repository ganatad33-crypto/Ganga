# נותנים בראש 2026 - אפליקציית סידור עבודה

אפליקציית ווב פשוטה לניהול משמרות לצוות: כל עובד נכנס דרך קישור, בוחר את שמו
מרשימה, ונרשם למשמרת בלוח השנה. המנהל/ת (**אמיר טייאר**) מאשר/ת או דוחה כל בקשה,
ויש היסטוריה לכל עובד. עובדת בדפדפן - גם באנדרואיד וגם באייפון - וכל מי
שיש לו את הקישור יכול להשתמש בה, בלי צורך בחשבון קלוד.

כדי שזה יעבוד צריך למלא פרטי חיבור למסד נתונים חינמי (Firebase) - זה לוקח
כ-10 דקות, חד פעמי. אחר כך פשוט מעלים את התיקייה לאתר חינמי ומקבלים קישור.

## שלב 1: יצירת מסד נתונים חינמי ב-Firebase

1. כנסו ל-https://console.firebase.google.com והתחברו עם חשבון Google.
2. לחצו **Add project** / **הוספת פרויקט**, תנו שם (למשל `notnim-berosh`), והמשיכו
   (אפשר לכבות Google Analytics - לא נדרש).
3. בתפריט הצד לחצו **Build > Firestore Database**, ואז **Create database**.
   - בחרו מיקום שרת (Location) - כל מיקום קרוב אליכם מתאים (למשל `eur3` לאירופה).
   - בחרו **Start in production mode**.
4. אחרי שהמסד נוצר, עברו ללשונית **Rules** ותחליפו את התוכן בתוכן הקובץ
   [`firestore.rules`](./firestore.rules) שנמצא בתיקייה הזו. לחצו **Publish**.
5. חזרו לתפריט הצד ולחצו על גלגל השיניים ⚙️ ליד "Project Overview" ואז
   **Project settings**. גללו למטה ל-"Your apps", לחצו על סמל ה-Web `</>`,
   תנו שם לאפליקציה ולחצו **Register app**.
6. יופיע קטע קוד עם אובייקט בשם `firebaseConfig` שנראה כך:
   ```js
   const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "notnim-berosh.firebaseapp.com",
     projectId: "notnim-berosh",
     storageBucket: "notnim-berosh.appspot.com",
     messagingSenderId: "123456789",
     appId: "1:123456789:web:abcdef"
   };
   ```
   העתיקו את הערכים האלה לתוך הקובץ [`js/firebase-config.js`](./js/firebase-config.js)
   במקום הכתובות `PASTE_...`.

זהו - שלב ה-Firebase הסתיים.

## שלב 2: פרסום האתר וקבלת קישור

הדרך הכי מהירה (בלי התקנות, בלי שורת פקודה):

1. כנסו ל-https://app.netlify.com/drop
2. גררו את כל תיקיית הפרויקט (התיקייה הזו, עם `index.html` בפנים) לתוך הדף.
3. תוך שניות תקבלו קישור ציבורי חי (למשל `https://xyz123.netlify.app`) -
   זה הקישור לשליחה לכל הצוות.

> טיפ: ב-Netlify אפשר גם לפתוח חשבון חינמי ולקשר לריפו ב-GitHub כדי שכל
> `git push` יעדכן את האתר אוטומטית - אבל זה לא חובה, גרירת תיקייה מספיקה.

## שלב 3: שימוש יומיומי

- **עובד/ת**: פותח/ת את הקישור, בוחר/ת את השם שלו/ה מהתפריט למעלה, לוחצ/ת
  על יום בלוח, ובוחר/ת "הרשמה" למשמרת הבוקר / הרגילה / הלילה. הבקשה מופיעה
  כ"ממתין לאישור" עד שהמנהל/ת מאשר/ת.
- **מנהל/ת (אמיר טייאר)**: בוחר/ת בשם **אמיר טייאר** מהתפריט למעלה - נפתחת לשונית
  **ניהול** נוספת עם:
  - **בקשות ממתינות לאישור** - כל בקשה חדשה מופיעה כאן לאישור/דחייה.
  - **רשימת עובדים** - הוספה/הסרה של שמות עובדים (רק שמות מהרשימה הזו
    מופיעים בתפריט הבחירה למעלה).
  - **היסטוריית עבודה לפי עובד** - בוחרים עובד ורואים את כל המשמרות שלו,
    כולל כמה אושרו/ממתינות/נדחו.

## הוספה למסך הבית (כדי שיראה כמו אפליקציה)

- **אנדרואיד (Chrome)**: פותחים את הקישור > תפריט שלוש הנקודות > "הוספה
  למסך הבית" / "התקן אפליקציה".
- **אייפון (Safari)**: פותחים את הקישור > כפתור השיתוף (הריבוע עם החץ) >
  "הוספה למסך הבית".

לאחר מכן האפליקציה תיפתח כמו אפליקציה רגילה, עם אייקון משלה, בלי שורת
כתובת של הדפדפן.

## אבטחה ומגבלות (חשוב לדעת)

כדי לשמור על הפשטות, אין באפליקציה מנגנון התחברות/סיסמה - **כל מי שיש לו
את הקישור יכול לראות ולערוך את לוח המשמרות**, בדיוק כמו קובץ Excel משותף
בקישור. זה מתאים לצוות סגור שסומך על החברים בו. אם בעתיד תרצו להוסיף שכבת
הגנה (למשל קוד גישה משותף לצוות), אפשר להרחיב את האפליקציה בקלות - רק
תגידו.

## מבנה הפרויקט

```
index.html            עמוד האפליקציה
css/style.css          עיצוב
js/firebase-config.js  פרטי החיבור למסד הנתונים (למלא בשלב 1)
js/app.js              כל הלוגיקה (לוח שנה, הרשמה, אישורים, היסטוריה)
manifest.json + sw.js  תמיכה בהתקנה כאפליקציה (PWA)
firestore.rules        חוקי אבטחה להעתקה ל-Firebase Console
icons/                 אייקון האפליקציה
```

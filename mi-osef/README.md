# 🚸 מי אוסף — הלוז השבועי של המשפחה

מי אוסף כל ילד, בכל יום. אבא ביום ראשון, אמא ביום שני, סבתא ביום שלישי —
וכשאין אף אחד, האפליקציה אומרת את זה בזמן ולא בדיעבד.

האפליקציה עובדת בטלפון, מותקנת למסך הבית, ופועלת גם בלי אינטרנט.

---

## מה יש בפנים

| | |
|---|---|
| **מסלול היום** | תחנות היום לפי שעה, עם אחראי בצבע שלו. תחנה בלי אחראי מסומנת באדום ולא נעלמת מהעין |
| **לוז שבועי** | טבלה של ימים × ילדים. שינוי בתא = השבוע הזה בלבד או כל השבועות |
| **תזכורות** | התראה לפני כל איסוף שאתה אחראי עליו, וקפיצה בכניסה לאפליקציה ביום שאתה בתורנות |
| **בקשות איסוף** | קריאה פתוחה — הראשון שנרשם סוגר אותה |
| **הסדרים הדדיים** | סיכום קבוע עם הורה אחר. צד אחד מקליד, הצד השני מאשר, ורק אז זה נכנס ללוז |
| **אנשי קשר** | על כל הסדר: למי לחייג אם משהו משתבש, וכפתור "לא אצליח להגיע" ששולח התראה דחופה |
| **מעגלי חשיפה** | הבית רואה הכול; הורה מחובר רואה פריט אחד; אפשר לבדוק הכול בעיניים של הצד השני |
| **דרגות בתוך הבית** | מלא · מוגבל (בלי פירוט של תורים רפואיים) · לפי שיבוץ |
| **מצב טסט** | עותק נפרד לניסויים, עם איפוס בלחיצה |
| **כפתורי הסבר** | ליד כל אלמנט, ומדריך מרוכז בהגדרות |

## הרצה מהירה

```bash
cd mi-osef
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

בלי הגדרות נוספות האפליקציה רצה ב**מצב הדגמה**: הכול נשמר במכשיר, בלי
חשבון ובלי שרת. אפשר לבנות לוז אמיתי ולעבוד ככה — פשוט אין סנכרון בין
מכשירים.

**קובץ יחיד לשליחה מהירה:** `node build.js` מייצר את `dist/miosef.html`
— קובץ אחד שאפשר לשלוח בוואטסאפ ולפתוח בטלפון. להתקנה למסך הבית
ולהתראות צריך את הגרסה הרגילה.

## חיבור לשרת — סנכרון בין כל בני המשפחה

### 1. פרויקט Supabase

צרו פרויקט חינמי ב־[supabase.com](https://supabase.com). ב־**SQL Editor**
הריצו את `supabase/schema.sql`. הוא יוצר את הטבלאות, את הרשאות השורה
(מי רואה מה) ואת הסנכרון החי.

### 2. הדבקת המפתחות

מ־**Project Settings → API** מעתיקים את ה־URL ואת מפתח `anon`, ומדביקים
ב־`js/config.js`:

```js
SUPABASE_URL: 'https://xxxx.supabase.co',
SUPABASE_ANON_KEY: 'eyJhbGciOi...'
```

> מפתח ה־`anon` נועד לרוץ בדפדפן. מה שמגן על הנתונים הוא ה־RLS
> שבסכימה, לא הסתרת המפתח. את מפתח ה־`service_role` **אין** לשים כאן.

### 3. כניסה

**ברירת המחדל: קוד למייל — חינם, ועובד מיד.** אין מה להגדיר; Supabase
שולח את המייל בעצמו. כדי שיישלח קוד בן שש ספרות ולא רק קישור, ב־
**Authentication → Email Templates → Magic Link** מוסיפים לתבנית שורה:

```html
<p>הקוד שלך: <b>{{ .Token }}</b></p>
```

(גם בלי זה אפשר פשוט ללחוץ על הקישור שבמייל — שתי הדרכים עובדות.)

**שדרוג בהמשך: קוד ב־SMS.** נוח יותר לסבים, אבל דורש ספק הודעות בתשלום.
מפעילים **Authentication → Providers → Phone**, מחברים Twilio או Vonage,
ומשנים ב־`js/config.js`:

```js
LOGIN: 'phone',
```

### 4. התראות פוש

```bash
npx web-push generate-vapid-keys
```

את המפתח הציבורי מדביקים ב־`js/config.js` תחת `VAPID_PUBLIC_KEY`, ואז:

```bash
supabase functions deploy notify --no-verify-jwt
supabase secrets set VAPID_PUBLIC=... VAPID_PRIVATE=... VAPID_SUBJECT=mailto:you@example.com
```

ולבסוף מתזמנים את הפונקציה כל חמש דקות — **Database → Cron**:

```sql
select cron.schedule('miosef-notify', '*/5 * * * *', $$
  select net.http_post(
    url     := 'https://<PROJECT>.supabase.co/functions/v1/notify',
    headers := '{"Authorization":"Bearer <SERVICE_ROLE_KEY>"}'::jsonb
  );
$$);
```

התזכורות נשלחות מהשרת ולא מהטלפון — כדי שיגיעו גם אם הטלפון היה כבוי.

## התקנה בטלפון

**אנדרואיד:** פותחים את הכתובת בכרום → תפריט → "הוספה למסך הבית".
ההתראות עובדות מיד.

**אייפון:** פותחים בספארי → שיתוף → "הוספה למסך הבית". **חובה** —
באייפון התראות פוש עובדות רק באפליקציה מותקנת, ורק מ־iOS 16.4 ומעלה.

## פריסה חינמית

הרפוזיטורי כבר ב־GitHub, ויש בו workflow מוכן
(`.github/workflows/pages.yml`) שמפרסם את האתר בכל דחיפה.

**מה שצריך לעשות פעם אחת:** ב־GitHub → **Settings → Pages → Source**
לבחור **GitHub Actions**. זהו. תוך דקה־שתיים מתקבלת כתובת קבועה:

```
https://<שם-המשתמש>.github.io/Ganga/mi-osef/
```

> אין אפשרות לבחור תיקייה כמו `/mi-osef` במסך של Pages — הבחירה שם
> מוגבלת לשורש או ל־`docs`. לכן הפרסום נעשה דרך Actions, שמעלה את שתי
> האפליקציות יחד: ניהול המלאי בשורש ו"מי אוסף" בתיקייה שלה.

הכתובת חייבת להיות ב־HTTPS: בלעדיה Service Worker, התקנה למסך הבית
והתראות פשוט לא עובדים.

## איפה הנתונים

במצב הדגמה — במכשיר בלבד. במצב מחובר — בשרת שלכם, עם גיבוי מקומי
בכל מכשיר כדי שהאפליקציה תעבוד גם בלי קליטה.

הרשאות נאכפות בבסיס הנתונים עצמו, לא באפליקציה: מי שאינו בן הבית לא
מקבל את השורה בכלל. שיתוף עם משפחה אחרת עובר דרך טבלת ההסדרים בלבד,
שמכילה שם פרטי, מקום, שעה ואנשי קשר — ולא את שאר הלוז.

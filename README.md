# סיכום קבוצת וואטסאפ

דף אינטרנט פשוט: מייצאים צ'אט של קבוצה מוואטסאפ, גוררים את הקובץ לדף, ומקבלים סיכום מסודר בעברית — נושאים שעלו, החלטות, משימות, ותאריכים/לינקים שכדאי לזכור.

הכל רץ בדפדפן. אין שרת, אין התקנה, ואין חיבור לחשבון הוואטסאפ (ולכן אין שום סיכון לחסימה).

## איך משתמשים

1. **מייצאים את הצ'אט מהטלפון:** פותחים את הקבוצה → שם הקבוצה / שלוש נקודות → **ייצוא צ'אט** → **ללא מדיה** → שולחים לעצמכם ומורידים למחשב.
   - אנדרואיד מייצר קובץ `.txt`
   - אייפון מייצר קובץ `.zip` — אפשר להעלות אותו כמו שהוא
2. פותחים את `index.html` (או את הגרסה המפורסמת ב-GitHub Pages).
3. מכניסים מפתח API של Anthropic (מנפיקים ב-[console.anthropic.com](https://console.anthropic.com/settings/keys)). אפשר לסמן "לזכור" והוא יישמר בדפדפן.
4. גוררים את קובץ הייצוא. הדף מציג כמה הודעות יש, כמה משתתפים ומאיזה תאריכים.
5. בוחרים טווח תאריכים (ברירת מחדל: 30 הימים האחרונים), סגנון סיכום, ואופציונלית "מיקוד" (למשל: "רק מה שקשור לתשלומים").
6. לוחצים **סכמו לי את הקבוצה**. את התוצאה אפשר להעתיק או להוריד כקובץ Markdown.

## מה קורה מאחורי הקלעים

- הדף מפענח את פורמט הייצוא של וואטסאפ (אנדרואיד ואייפון, עברית ואנגלית, AM/PM), מזהה אוטומטית אם התאריכים הם יום/חודש או חודש/יום, מאחד הודעות מרובות שורות, ומסנן הודעות מערכת, מדיה והודעות שנמחקו.
- הטקסט של ההודעות בטווח שנבחר נשלח **ישירות מהדפדפן** ל-API של Anthropic עם המפתח שלכם. שום דבר לא עובר או נשמר בשרת אחר.
- שיחה ארוכה במיוחד מחולקת לחלקים, כל חלק מסוכם בנפרד, ואז הסיכומים מאוחדים לסיכום אחד.

## עלות

הסיכום מחויב לחשבון Anthropic שלכם לפי כמות הטקסט. הדף מציג הערכת טוקנים לפני ההרצה ואת הכמות בפועל אחריה. לרוב הקבוצות, סיכום של חודש עולה סנטים בודדים עד כמה עשרות סנטים, תלוי במודל שנבחר.

## פרטיות

- מפתח ה-API נשמר (אם ביקשתם) רק ב-`localStorage` של הדפדפן שלכם.
- תוכן הצ'אט לא נשמר בשום מקום — הוא נשלח ל-Anthropic לצורך הסיכום בלבד ונעלם כשסוגרים את הדף.

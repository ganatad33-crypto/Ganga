# 🍿 חטיף אהוב — אתר לאוהבי חטיפים

אתר סטטי בעברית (RTL) שנבנה בעזרת [21st.dev](https://21st.dev).
נמצא בתיקייה `snacks/` ולא נוגע באפליקציית ניהול המלאי שבשורש הריפו.

**פתיחה:** `snacks/index.html` — בלי בנייה, בלי התקנות, בלי אינטרנט.
בגיטהאב פייג'ס הכתובת תהיה `…/snacks/`.

## מה יש באתר

| חלק | מה הוא עושה |
|---|---|
| **Hero** | כותרת ענקית, חטיפים מרחפים, וכפתור **🎲 הגרל לי חטיף** שגולל לחטיף אקראי ומדגיש אותו |
| **קטלוג** | 12 חטיפים בכרטיסים: ציון טעם, דירוג פריכות, קטגוריה, ומה שותים עם זה |
| **סינון וחיפוש** | צ׳יפים לפי טעם (מלוח / מתוק / חריף / חמוץ) + חיפוש חופשי בשם ובתיאור |
| **מועדפים** | לחיצה על ❤ בכרטיס — נשמר ב-`localStorage` של הדפדפן |
| **חטיף החודש** | באנר ספוטלייט שנבנה אוטומטית מהחטיף שמוגדר ב-`SNACK_OF_MONTH` |
| **הסקר הגדול** | הצבעה אחת למכשיר, עם עמודות תוצאה מונפשות ואפשרות לבטל |
| **מועדון החטיפים** | טופס הרשמה עם ולידציה (צד לקוח בלבד — אין שרת) |

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | כל המבנה של הדף |
| `css/snacks.css` | העיצוב כולו (טוקנים של צבעים למעלה) |
| `js/data.js` | **התוכן** — רשימת החטיפים, הקטגוריות, חטיף החודש והסקר |
| `js/snacks.js` | הלוגיקה: סינון, מועדפים, סקר, מונים ואנימציות |

הפונטים (Heebo + Rubik) נטענים מתיקיית `fonts/` המשותפת בשורש הפרויקט,
כך שאין שום תלות באינטרנט.

## איך מוסיפים חטיף

רק ב-`js/data.js` — מוסיפים אובייקט למערך `SNACKS`:

```js
{ id:'tortit', name:'טורטית', emoji:'🌮', cat:'salty', crunch:4, score:82, classic:true,
  tag:'הכיס שאפשר למלא',
  text:'משולש פריך שמחכה לממרח. גם לבד הוא מסתדר מצוין.',
  pair:'עם חומוס וקצת פפריקה.' }
```

- `cat` — אחד מ־`salty` / `sweet` / `spicy` / `sour` (הקטגוריות מוגדרות ב-`SNACK_CATS`)
- `crunch` — פריכות 1–5 · `score` — ציון טעם 0–100 · `classic: true` — מוסיף תג "קלאסיקה"

הצ׳יפים, המונים והחיפוש מתעדכנים מעצמם. להחלפת חטיף החודש — משנים את
`SNACK_OF_MONTH` למזהה אחר; להחלפת אפשרויות הסקר — עורכים את `POLL`.

## עיצוב

סגנון neo-brutalist בצבעי ממתקים: מסגרות שחורות עבות, צללים קשיחים,
פינות מעוגלות וטיפוגרפיה שמנה. פלטת הצבעים נמצאת ב-`:root` בראש
`css/snacks.css` — שינוי צבע אחד שם משנה את כל האתר.

אפקט ההטיה התלת־ממדית של הכרטיסים מבוסס על רכיב
[BentoItem](https://21st.dev/@dhileepkumargm/bento-item) מ-21st.dev,
מותאם לוונילה JS. הוא פועל רק בעכבר, ומכובה אוטומטית במסכי מגע
ובמצב `prefers-reduced-motion`.

## הערות

- אין שרת: מועדפים, הצבעה בסקר והרשמה למועדון נשמרים בדפדפן בלבד.
- מספרי ההצבעות והסטטיסטיקות הם נתוני פתיחה לתצוגה, לא נתונים אמיתיים.
- ה-Service Worker של אפליקציית המלאי (`sw.js` בשורש) עובד cache-first על כל
  המקור. אם האפליקציה מותקנת במכשיר וגם פותחים ממנו את האתר הזה, ייתכן
  שגרסה ישנה תישמר במטמון — רענון קשיח או העלאת `VERSION` ב-`sw.js` פותרים.

# 🦆 דוכן הכפל

משחק תרגול לוח הכפל בסגנון דוכן הגרלות בלונה פארק — לילדים.

## איך משחקים

בכל סיבוב מופיע תרגיל כפל למעלה (למשל `7 × 8 = ?`). ברווזים צבעוניים,
כל אחד עם מספר על הגב, שוחים קדימה ואחורה בבריכה. לוחצים (או נוגעים,
בטלפון) על הברווז עם התשובה הנכונה כדי "לירות" בו עם הרובה שבתחתית המסך.

- **פגיעה נכונה** → נקודות, כוכב ברצף ההצלחות, וברווז שוקע בשמחה.
- **3 פגיעות נכונות ברצף** → עולים רמה: הברווזים שוחים מהר יותר,
  מצטרפים עוד ברווזים, ותרגילי הכפל כוללים מספרים גבוהים יותר.
- **2 פגיעות שגויות ברצף** → יורדים רמה בעדינות, כדי שהמשחק תמיד יישאר
  ברמת אתגר מתאימה — לא קל מדי ולא מתסכל.

אין "משחק נגמר" — זהו תרגול מתמשך שמתכוונן אוטומטית לפי הביצועים.

## מבנה

קובץ HTML/CSS/JS עצמאי לחלוטין (בלי תלות באינטרנט, פונטים מקומיים
מ-`../fonts`) — `index.html` + `style.css` + `game.js`. אפשר לפתוח
ישירות או להגיש דרך GitHub Pages לצד שאר האפליקציות בריפו הזה.
